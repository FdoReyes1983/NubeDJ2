# Nube DJ 2 (v0.1.0 - motor base)

App DJ Android nueva, motor de audio en C++ con Oboe (baja latencia).

Incluye: 2 decks, carga de audio local, PLAY/CUE, jog con scratch, tempo, volumen,
crossfader, VU, waveform general. El APK de debug se genera con GitHub Actions
(`.github/workflows/android-debug.yml`) y se descarga en Actions > Artifacts.
